\begin{remark}\label{rl-001D}
  Stated another way: given an \(S\)-scheme \(A\) and an \(A\)-point \(x:A\to X\), we have the homomorphism of algebraic spaces over \(A\)
  \[\alpha_A:\Aut_{\mathcal X}(x) \to G\times_SA\]
  from Equation~\ref{eqn:inertia-exact-sequence-over-point}. Then \(x\) belongs to \(X^G\) if and only if \(\alpha_A\) admits a section after base change along some fppf cover \(A' \twoheadrightarrow A\).

  \bigskip
  
  \noindent Stated yet another way: \(x\in X(A)\) belongs to \(X^G\) if and only if \(\St^G_X(x) = G\times_S A\).
\end{remark}
