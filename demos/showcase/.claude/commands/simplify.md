description: Apply the loom simplify mode to a key of this quilt
argument-hint: KEY
---

Apply `ai/modes/simplify.md` to `$ARGUMENTS`. `loom ai runs` lists the open runs and `loom ai start "a name"` opens one; pass it as `--run` on every command that takes it, since nothing sets `$LOOM_RUN`. Follow the mode file exactly; its checklist is the output contract.
