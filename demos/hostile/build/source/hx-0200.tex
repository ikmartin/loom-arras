\begin{lemma}[An id that is a path]\label{../../escape}
A label that is a relative path. If an id ever becomes a filename, this one is written outside the build directory.
\end{lemma}

\begin{lemma}[An id with a percent and a slash]\label{hx/0004\%2e\%2e}
Anything that percent-decodes on the way to a URL decodes on the way to a path too.
\end{lemma}
