description: Apply the loom ingest mode to a key of this quilt
argument-hint: KEY
---

Apply `ai/modes/ingest.md` to `$ARGUMENTS`. `loom session list` lists the open sessions and `loom ai start "a name"` opens one and makes it active; writing lands there, and `--session` names another. Follow the mode file exactly; its checklist is the output contract.
