---
name: loom-referee
description: when the user asks to referee, review, or find gaps or errors in a node of this quilt
---

Run `loom ai orient` if you have not done so, and `loom ai runs` to see the open sessions; `loom ai start "a name"` opens a new one and makes it active. Writing lands in the active session, and `--session` names another. Read `ai/modes/referee.md` and follow it exactly. Begin with the mode's first command. The target is `$ARGUMENTS`.
