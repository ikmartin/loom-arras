# ai/

The optional AI layer of this quilt, created by `loom ai init` (book chapter 11). An agent working here reads `orientation.md` first, through `loom ai orient`.

Yours to edit: `modes/*.md`, the mode templates. `loom upgrade` leaves an edited mode file alone and writes the new shipped version beside it as `<mode>.md.new` for you to merge.

Regenerated by `loom upgrade`, never edited by hand: `orientation.md`, this file, `.loom-modes-version`, `../CLAUDE.md`, `../AGENTS.md`, and, when they exist, `../.claude/settings.json`, `../.claude/skills/loom-*/SKILL.md`, `../.claude/commands/*.md`.

Written by runs: `runs/<timestamp>-<slug>/`. Loom writes `run.toml`, `run.log` (every command invoked with `--run`), and `annotations.json` (through `loom comment --run`); the agent writes everything else, named by mode and target. Runs are committed except `bundle-*.tex`, which is regenerable.
