# ai/

The optional AI layer of this quilt, created by `loom ai init`. An agent working here reads `orientation.md`, `rules.md`, `formatting.md` and the index of the modes through `loom ai orient`, and one mode in full through `loom ai mode NAME`.

Yours to edit: `orientation.md`, `rules.md`, `formatting.md` and `modes/*.md`. `loom upgrade` leaves an edited one alone and writes the new shipped version beside it as `<name>.md.new` for you to merge. A mode's `When it fits:` line is what the index shows.

Regenerated by `loom upgrade`, never edited by hand: this file, `.loom-modes-version`, loom's one line in `../CLAUDE.md`, `../AGENTS.md` and `../GEMINI.md`, `../.claude/settings.json` and `../.codex/rules/loom.rules`, and, when agents here attach over MCP, the files that start its server for each app (`../.mcp.json`, `../.codex/config.toml`, `../.gemini/settings.json`, `../.cursor/mcp.json`), which are gitignored because they name this machine's paths.

Written in sessions, which live in `.loom/sessions/<id>/` and not here. Loom writes `run.log` there (every command invoked with `--session`) and the transcript, `inbox.jsonl`, through `loom session say`, and appends the annotation log through `loom annotate`; an agent writes there only what a report cites, such as a script. Sessions are committed.
