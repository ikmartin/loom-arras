---
name: loom-brainstorm
description: when the user wants to explore, brainstorm, or plan a topic before proving anything
---

Run `loom ai orient` if you have not done so, and `loom session list` to see the open sessions; `loom ai start "a name"` opens a new one and makes it active. Writing lands in the active session, and `--session` names another. Read `ai/modes/brainstorm.md` and follow it exactly. Begin with the mode's first command.
