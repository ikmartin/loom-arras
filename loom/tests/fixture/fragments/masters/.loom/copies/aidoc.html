Widgets, gadgets, and their fixed loci

THE SYNTHETIC QUILT

1. Introduction

This paper studies widgets. The basic identity is

\[\tag{1}\sigma^2 = \mathrm{id},\]

which we use throughout.1 1The name comes from nowhere. The Gromov–Witten theory of gadgets is not touched. See [1, Chapter II] for schemes and [2, Theorem 2.1] for cycle groups; the lemma [2, Lemma 9] is not in the digest.

Definition 1.1 (Widget)

A widget is a pair \((X,\sigma)\) of a set and an involution \(\sigma\) of \(X\), so that (1) holds. Its fixed locus is

\[\tag{2}\Fix(\sigma) = \{x \in X : \sigma x = x\}.\]

Remark 1.2

Gadgets exist: take \(X = \{1,2\}\) with the swap. Compare [2, Theorem 2.1].

Lemma 1.3 (Orbits)

Every orbit of a widget has at most two points, and one exactly when its point is fixed; compare (2) in Definition  1.1.

Proof

The orbit of \(x\) is \(\{x, \sigma x\}\) because

\[\tag{3}\sigma(\sigma x) = x\]

by (1). □

2. Results

The main results, with one proof deferred to the end of the section.

Theorem 2.1 (Parity)

Let \((X,\sigma)\) be a finite widget. Then \(|X| \equiv |\Fix(\sigma)| \pmod 2\).

First proof

By Lemma  1.3 the set \(X\) is a disjoint union of orbits of size one or two. □

Second proof

Count fixed points of the permutation \(\sigma\) directly, using (3) from the proof of Lemma  1.3 and Definition  1.1. □

Proposition 2.2 (Two arguments)

A widget with \(|X| = 1\) has a fixed point.

Proof

Lemma 2.3 (Deferred)

The composite of two widget maps is a widget map.

Definition 2.4 (Gadget)

A gadget is a widget whose involution has no fixed point.

Proof of Lemma  2.3

Both maps commute with the involutions, so their composite does. Here we use Definition  2.4 only for notation. □
