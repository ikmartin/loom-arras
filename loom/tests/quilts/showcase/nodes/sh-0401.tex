\begin{lemma}[Support]\label{sh-0401}
Let $w$ be a balanced weighting with $w \geq 0$ and $w \neq 0$. Then $\supp(w)$ contains a directed cycle.
\end{lemma}
\begin{proof}
Pick $a_{0}$ with $w(a_{0}) > 0$. Since $(\bd w)(t(a_{0})) = 0$ and the arrow $a_{0}$ contributes positively to that sum, some arrow $a_{1}$ with $s(a_{1}) = t(a_{0})$ has $w(a_{1}) > 0$. Repeating, we obtain an infinite walk inside $\supp(w)$, which is finite, so some vertex repeats and the walk contains a directed cycle.
\end{proof}
