---
name: loom-simplify
description: when the user asks to shorten, tighten, or simplify a node's text without changing its mathematics
---

Run `loom ai orient` if you have not done so, and `loom ai runs` to see the open sessions; `loom ai start "a name"` opens a new one and makes it active. Writing lands in the active session, and `--session` names another. Read `ai/modes/simplify.md` and follow it exactly. Begin with the mode's first command. The target is `$ARGUMENTS`.
