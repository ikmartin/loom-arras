---
name: loom-referee
description: when the user asks to referee, review, or find gaps or errors in a node of this quilt
---

Run `loom ai orient` if you have not done so this session, and `loom ai runs` to see the open runs; `loom ai start "a name"` opens a new one. Nothing sets `$LOOM_RUN`, so pass `--run` with the run's name on every command that takes it. Read `ai/modes/referee.md` and follow it exactly. Begin with the mode's first command. The target is `$ARGUMENTS`.
