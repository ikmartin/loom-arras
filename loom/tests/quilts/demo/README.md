# The loom demo quilt

A five-node paper about widgets, invented so that nothing in it is anyone's mathematics. It is what `loom init --demo` writes. Run `loom status`, `loom lint`, `loom deps dm-0003`, `loom bundle dm-0003`, and `loom serve` here to see every part of loom at work.

The quilt contract is summarised in CONTRACT.md.
