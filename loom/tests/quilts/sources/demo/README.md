# The loom demo quilt

A five-node paper about widgets, invented so that nothing in it is anyone's mathematics. It is what `loom init --demo` writes. Run `loom status`, `loom lint`, `loom deps dm-0003`, `loom source dm-0003 --closure`, and `loom serve` here to see every part of loom at work.

The quilt contract is summarised in CONTRACT.md.

The quilt also carries its AI layer (`ai/`, `CLAUDE.md`, `AGENTS.md`, and `.claude/` with permission settings and skill stubs, all written by `loom ai init --skills --permissions`) and one finished run, `ai/runs/2026-09-16T14-02-referee-dm-0003/`: a referee pass over the main theorem that left one objection and one suggestion through `loom comment --run`, a notes file, and a thread.
