\begin{definition}[Widget]\label{dm-0001}\label{def:widget}
A \emph{widget} is a pair $(X,\sigma)$ of a finite set $X$ and a map $\sigma\colon X\to X$ with $\sigma^2=\mathrm{id}$. Its \emph{fixed locus} is
\begin{equation}\label{eq:fix}
\Fix(\sigma) = \{x\in X : \sigma x = x\}.
\end{equation}
\end{definition}
