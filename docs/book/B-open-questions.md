# Appendix B. Open questions

> **Frozen history.** This book was superseded on 2026-10-26 by [`docs/design/`](../design/README.md), with formats in [`docs/specs/`](../specs/README.md) and contributor rules in [`docs/contributing.md`](../contributing.md). It is kept unchanged so that references to its sections and decision records still resolve. Do not edit it, and do not treat it as describing loom as it is or will be.

This appendix collected what the design could not settle and implementation had not, gathered from the chapters and specifications with the marker each carried there. It is empty, and the mechanism it indexed is gone.

Every question it held was either settled — and the chapter now states the answer as what loom does, rather than as a question with a working answer attached — or moved to **`docs/work-queue/`**, where it is one file carrying an observable trigger that says when it becomes worth doing. The chapters no longer end with "Open questions" sections, and `docs/work-queue/check.py` fails if one reappears.

So: for what the project has decided, read the chapters. For what it has not done, read the work queue. For why a decision changed under implementation, read Appendix A and `docs/deviations.md` (DR-107).

This file is kept rather than deleted so that the appendix lettering and every cross-reference to Appendices C through F still resolve.
