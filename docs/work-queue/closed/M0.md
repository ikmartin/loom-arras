## Deviations recorded

- DR-39: the book's 10.8 forbidden-word list cannot exclude `digest` and `proof`, because the manifest specification names fields `proofs`, `digest`, and a route `/digest/`. The guard test forbids `quilt`, `atomize`, `unravel`, and `loom <command>` phrases instead.
- Discovery, no DR needed: this SvelteKit release keeps the kit configuration inside `vite.config.ts` (the `sveltekit({adapter, ...})` plugin options); there is no `svelte.config.js`. The book's 13.4 tree lists none, so nothing to change.
- Discovery, no DR needed: `ruff`'s line-length rule E501 is disabled because the workspace's prose rule forbids hard-wrapping docstrings; `ruff format` still governs code width.

## Blocked on the user

- The workspace repository's `origin` points at `https://github.com/ikmartin/arras.git`, and no `ikmartin/loom-arras` repository exists on GitHub. The workspace is committed locally but not pushed. To publish it: create `github.com/ikmartin/loom-arras` and run `git remote set-url origin https://github.com/ikmartin/loom-arras.git && git push -u origin main` in `~/dev/loom-arras`.
