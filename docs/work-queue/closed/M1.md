# M1. Read a quilt

## Book says

`loom lint` on the demo quilt and the synthetic quilt reports exactly the diagnostics the fixture description lists; `loom deps` and `loom unravel` match hand-computed answers. The plan adds: `loom lint` on scratch quilts made from the three real papers completes without crashing, with the diagnostic counts recorded here.

## Deviations recorded

DR-40 through DR-53 in `docs/book/A-decision-records.md`, each with a row in `docs/deviations.md`. In one line each: the scanner reads by character offset and anchoring is enforced only where regions are moved; proofs attach by enclosure and nested statements are nodes; a leading `\cite` marks an external node; a section's label is not stolen from the next environment; inclusions resolve as TeX does; digest prefixes are citekey slugs; the preamble closure is transitive through local styles; non-UTF-8 sources are decoded with a warning; comments are blanked before every stage; ownership is per file while hierarchy is per master; a master's preamble yields no edges; `unreachable` is per file and not for digests; five diagnostic codes were added; unknown theorem-like environments are detected by a list of common names.

The ACGS paper found three scanner bugs during this milestone, all fixed and covered by `test_labels_with_spaces_commas_and_wrapped_refs`: references inside preamble macro bodies were counted, labels wrapped across a line break were not normalised, and single-label reference commands were split on commas.
