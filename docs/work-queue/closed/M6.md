Every command an agent uses takes `--run` (`LOOM_RUN` is its default) and appends to `run.log`: `bundle`, `comment`, `status`, `search`, `deps`, `unravel`, `lint`, `ai orient`.

## Deviations recorded

- DR-70: `ai/`, `refs/src/`, `refs/pdf/`, and `.claude/` are not scanned.
- DR-71: skills carry the target; slash commands are one-line wrappers; the permission settings deny per directory because deny precedes allow.
- DR-72: the agent launch passes a pointer to `loom ai orient --run RUN`, with `LOOM_RUN` set, not the orientation text; `--no-launch` exists; `run.toml` records the agent's name.
- Discovery: `loom ai promote` appends `loom ai promote FILE -> TARGET` to the run's `run.log`, and `loom ai check` excludes those targets, so the author's own promotion is not reported as an agent write; files changed within the first second of the run are ignored too, since `run.toml` records whole seconds.
- Discovery: `.loom-modes-version` records one hash per mode file rather than one for the set, so `upgrade` can refresh the unedited files and keep the edited ones individually.
- Discovery: Claude Code supports `@path` imports in `CLAUDE.md`; the generated root files stay the book's identical one-sentence copies, since `AGENTS.md` readers may not.
- Discovery: `loom bundle --run` logs only the flags actually given.
