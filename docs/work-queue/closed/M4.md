## Deviations recorded

- DR-62: files no master reaches are sectioned on their own, so a digest's headings become the `<citekey>-sec-<n>` section nodes the book promises and `loom id` labels headings in loose files. The conformance fixture gained three section nodes in the Kre99 digest.
- DR-63: a proof whose optional argument names only unknown labels attaches by position (adjacency, then enclosure) and the unknown label is reported as a dangling link, instead of being an unattached proof.
- DR-64: the id label of a heading is inserted directly after the heading's arguments, ahead of any label the author already had, so the id is the heading's first label under the same rule environments follow.
- DR-65: `atomize` and `inline` on a file that is not a master run the identity test through the first master that reaches it, in a scratch copy of the quilt with the rewritten file in place; when no master reaches the file the test is reported skipped.
- Discovery: the round trip `inline(atomize(F))` reproduces F up to blank lines between moved regions (moved text is trimmed to whole lines and written with one trailing newline).
- Discovery: `\usepackage{loom}` must be inserted after the first uncommented `\documentclass`; ACGS starts with a commented-out one, which put the package before the class and broke the copy's compile.
- Discovery: TeX writes non-UTF-8 bytes to its terminal output (relloc); every subprocess output is now decoded with replacement.
- Discovery: the fake TeX shim did not shift sectioning under `\nest`, so the identity test on an inlined `\nest` failed against the real `loom.sty`; the shim now shifts as the package does.
- Discovery: environment titles inside a brace group (`[{\cite[...]{Kre99}}]`) rendered with a one-character offset, turning the citekey into `e`; the inline converter now hands the group's own text to the recursion.

## Correction, 2026-09-16

The quilts this record describes were left holding three definitions of every node: the imported master with its ids inline, the atomized spine with `nodes/`, and the `inline` round-trip output. That is not what a quilt looks like — several masters are arrangements over one set of patches, not three copies of them — and it produced a `duplicate-id` error per node, which in turn made the publisher render the whole paper as pictures. `demos/man12` and `demos/acgs` were rebuilt with `loom atomize --sections --ignore-src` (DR-88), leaving one definition of each node and the imported master ignored; the round-trip that this record demonstrates is still run, but in a scratch copy. The identity results above are unchanged.
