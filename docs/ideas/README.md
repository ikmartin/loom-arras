# Ideas

Explorations of what loom could become, written so they can be shared and argued with. Nothing here is decided, planned or normative: where an idea and `docs/design/` disagree, the design wins, and an idea that cites the design may have gone stale since it was written.

An idea leaves this directory in one of three ways: the author commits to building it and it becomes a plan in `docs/plans/`; it acquires an observable trigger and becomes a work-queue item in `docs/work-queue/`; or it is dropped, and its file is deleted with the reason in the commit message.
