# plan sketch for the improvement of split view and a new "run view"

Run view: a new top-level view mode for viewing runs. Auto updated so that an ongoing run with a transcript displays like a chat interface. This is just below read view in the rail and just above the graph. I will also call this "chat view" sometimes; "chat view" and "run view" refer to the same thing.

Split view: a toggle in the upper right side of the screen which is available in views which enable it. Right now it should be toggle-able in chat view and in read view. The idea is that while navigating in chat
