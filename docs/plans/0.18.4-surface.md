# 0.18.4: the command surface, flags and help

## Context

The CLI study (`docs/reports/cli-study.md`, Part four E, F, G and I; Part five tables 2 and 3, and the help layout) found the command line broken against K1–K7 (book 1.12):
- **Seven aliases** for two commands. Commands that only refuse. Two commands that are others under another name (`review` is `build`; `check --no-compile` is `lint`). Two shapes for one act (`ai start`/`session new`, `ai name`/`session rename`, `agent check`/`doctor`).
- **`history`** takes words, so a typo reads as "no such key" and its flags apply to one word only.
- **One idea, several flags:**
  - `--author` on 15 commands and `--as` on 6, meaning four things;
  - `--to` as an option and as a positional;
  - two session resolvers that disagree. `sessions.resolve` reports an ambiguous name as not found, and `find_session` writes into deleted sessions.
- **Free strings accepted silently.** An `--engine troff` falls back to pdflatex. A `--kind` or `--tag` typo filters to nothing.
- **`--json` used as a dry run** on `fork` and `atomize --key`, while most writers have no dry run at all.
- **A help that is an alphabetical list** of 43 entries with cut descriptions, 14 of whose first lines are not sentences.
- **Three names** for the agent's documents.

**Decided with the author on 2026-10-03:**
- **Reserved codes.** `duplicate-id`, `dangling-link`, `missing-include`, `inclusion-cycle`, `double-inclusion` and `unreachable` stay bare: they are the reserved cross-publisher codes of `specs/diagnostics.md` §2. Every other code carries `loom:`.
- **Withdrawn, in words only.** What a person reads says "withdrawn" and "withdraw". The stored and wire names (`discarded` in the log, the manifest's `discarded`, the `discard` endpoint) stay, so no quilt's log changes.
- **"Agent document."** Every document in `drafting-ai/`, whether drafted from a working document or written by the agent from scratch, is an **agent document**. "AI draft", "AI copy" and "agent copy" go from the CLI, the viewer and the book.
- **The `refs` commands' flags** (`--author`, `--reason`, `--fetch`/`--resolve`) change in 0.18.5, when those commands become `loom library`.

## The work

### 1. One session resolver

- **The resolver.** `sessions.resolve(root, which, *, live=True)` raises rather than returning None:
  - `NotFoundError` names what matched nothing;
  - an ambiguous name is an `EnvError` naming the matches;
  - a deleted session is not found where `live` is set.
- **Its callers.** `cli/_common.find_session` keeps the active-session default and calls it, and every caller goes through one of the two:
  - `session.py`'s `use`, `rename`, `close` and `delete`;
  - `annotate`'s `_writer` (`review.py:375`);
  - the write API (`render/api.py:417, 451`).
- **Writes into deleted sessions.** A write into a deleted session is refused.
- **Tests:** ambiguous refused with both names; deleted not found for writes and found for `session use --deleted` and readers.

### 2. Flags (K2), outside `refs`

- **`--as NAME` is who acts**, replacing `--author` on:
  - `accept` and `annotate`;
  - `session new`/`use`/`rename`/`close`/`delete`;
  - `session say`/`next`/`watch`, which already use `--as`.

  One resolver goes with it, `_common.writer`, which refuses an unnamed agent. `whoever` folds into it for the commands that only attribute.
- **`init --author` goes.** It is the legacy quilt attribution, and the reviewer identity comes from Settings or git.
- **`ai discard --author` becomes `--by`.** It filters by who wrote, and is not who acts.
- **`--name` names something new:**
  - `fork --as ID` becomes `fork --name ID`;
  - `session new` and `session rename` take `--name` in place of a positional title.
- **`--to FILE` is always an option, with one path rule.** A helper `_common.destination(quilt, path, writes_drafting=False)`:
  - refuses a path among the quilt's sources or drafting directories, unless the command writes a drafting document;
  - refuses one that exists, unless the command overwrites by design.

  `atomize`'s positional `DEST` goes (the study's G6 precedence bug), and the rule applies to `id`, `deloom`, `linearize`, `history restore`, `adopt --to` and `sync status --patch --to`.
- **`--why` replaces `--reason`** wherever a reason is asked, outside `refs`.
- **`--dry-run` on every writer outside `refs`.** It is reported as `Report(dry_run=True)` naming what would be written, and nothing is written:
  - `accept`, `annotate`, `import`, `init`;
  - `deloom`, `draft`, `linearize`, `live`, `mv`, `stamp`, `upgrade`;
  - `fork` and `atomize --key`, whose `--json` stops being a dry run (K4);
  - the `session` writers and `ai init`/`refresh`/`discard`;
  - `sync init`/`documents`/`incorporate`/`publish`.

  `adopt`'s preview is its dry run, and `--json` on it reports the preview without being one.
- **Tests:** a dry run of each writer leaves the quilt's files byte-identical (a snapshot before and after, from the output case table).

### 3. Removals and reshapes (K1)

**Removals:**
- `unravel`, `reach` and `pop` go; `downstream` is the command.
- `delete`, `rm` and `remove` go. The main group's unknown-command handler answers those three names with why loom does not delete, naming `loom downstream ID`, and exits 2.
- `review` goes: `build` publishes, and `status --stale` lists.
- `check --no-compile` goes: `lint` is that.
- `ai start` goes; `session new` replaces it.
- `ai name` goes; `session rename` replaces it.
- `agent check` goes. `doctor --agents` takes its full report: the start, resume and prompt lines, and its faults with their fixes. Every message that named `loom agent check` names `loom doctor --agents`.
- `ai check` goes, until a write can be attributed to an agent by something other than its time.
- `sync patch` goes; `sync status --patch [--to FILE]` prints the incoming diff. The commands that named it follow (`cli/sync.py:155, 199, 273`, `sync.py:459`).

**Reshapes:**
- **`history` becomes a group** whose unknown subcommand is read as a key:
  - `history` lists the steps;
  - `history KEY` lists that key's versions;
  - `history show NAME [--plain]`;
  - `history restore NAME --to FILE`;
  - `history verify`.

  Each takes only its own flags.
- **`session say` is for people and agents alike.** It carries the person's marked packet that `send` carried, and `session send` goes.
- **`ai init` works in a quilt that has `ai/`.** It refreshes what `upgrade` would, and writes `ai/ai-config.toml` (today only `init --ai` does); `init --ai` calls it.

**Agent commands.** `AGENT_COMMANDS` (`ai/layout.py:33`) follows:
- `downstream` stays, and `unravel`, `pop` and `reach` go;
- `ai start`, `ai name` and `ai check` go;
- `session send` goes, and `session say` stays;
- `history` becomes `history`, `history show` and `history verify`. `history restore` writes a drafting document, so it stays the author's.

Every command an agent can run today remains, or its replacement is in the set.

### 4. Validation (K3)

- **Typed options:**
  - `--engine` is a `click.Choice` of the engines `tex/runner.py` knows (`compile`);
  - `ai annotations --severity/--kind/--status` are `Choice`s with the same values as `status` and `annotate`;
  - `--prefix` is checked against the id grammar (`new`, `id`, `init`);
  - `fork --from @N` is a typed step.
- **Checked against the quilt** before anything prints or logs: `status --kind/--master/--tag`.
- **Keys before work.** `deps`, `downstream`, `new`, `compile`, `status --explain` and `annotate` resolve their keys and sessions before writing a session log or scanning twice.
- **Tests:** for every leaf command in `tests/output_cases`, an argument that names nothing exits 2 and leaves the quilt byte-identical. The case table gains these refusal cases, and 0.18.3's check asserts their exits.

### 5. Help (K6)

- **A custom group** `cli/help.LoomGroup` lists commands in the study's task sections, the person's first: Start, Write, Review, History, Library, Agents, Publish, Upkeep. Each section is one line saying what it is for.
- **Agent commands** are marked from `AGENT_COMMANDS`.
- **Full first sentences:** the 14 leaf commands and 6 groups whose first lines are noun phrases get them, and every option without help gets a line.
- **Bare `loom`** prints the help and exits 0.
- **The generators keep working.** It overrides only how help is formatted, so `gen_cli_reference.py`, `command_tree()` and the test walks of the click tree are unchanged. The reference lists sections in the same order.
- **Test:** every leaf command appears in exactly one section, and every first help line ends with a full stop.

### 6. Names (K7)

- **"Agent document" everywhere:**
  - the CLI (`adopt`, `ai drafts`/`refresh`, `draft`, `review.py`'s mentions);
  - the incoming labels (`adopt.py:691`, `render/incoming.py:297, 320`, so "Incoming from agent document “X”");
  - arras (`AdoptionContribution.svelte`, `routes/review/+page.svelte`);
  - the book.

  One drafted from a working document says so where it matters: "drafted from drafting/main.tex". `ai refresh`'s match on the message prefix (`cli/ai.py:419, 430`) moves to a field.
- **"Withdrawn" in every word a person reads:**
  - the CLI (`withdrew a-…`);
  - arras's labels (`VerbRow`, `AnnotationBox`, `ContextItem`, `SessionDid`);
  - the book.

  The data names stay.
- **"Bundle" leaves the output.** `check --bundles` becomes `check --closures`, and the JSON key and the diagnostic `loom:bundle-failed` become `closures` and `loom:closure-failed` (`specs/diagnostics.md`).
- **A test** asserts every emitted code is reserved or `loom:`-prefixed (`test_all_emitted_codes_are_known` already walks the codes).

### 7. Everything that names a command follows

- **The book:**
  - chapter 12, regenerated, with its hand-written 12.1 conventions (`--as`, `--to`'s rule, `--dry-run`, the help);
  - chapters 3, 4, 7, 9, 10, 11 and 17;
  - appendices C and D, through `appendices.py --write`.
- **The agents' files:** `ai/rules.md`, the orientation and every mode template; the demo copies and the permission files, through `gen_quilts.py`, which also moves from `ai start` to `session new`.
- **Arras's labels.**
- **The tests** (about 30 files use `--author`) and `tests/output_cases`.
- **No compatibility layer.**

## Delivery

Built on 2026-10-03, as one landing (DR-330-ikmartin).

**The shared pieces:**
- `sessions.resolve` raises `SessionNotFound` with its matches; `cli/_common.find_session` and the write API's `_resolve_session` both go through it, and a write into a deleted session is refused.
- `cli/_common.destination(quilt, path, *, drafting, source, overwrite)`: the one `--to` rule. `drafting` for `linearize` and `history restore`; `source` for `atomize`, whose output takes its source's place, which the plan did not foresee.
- `cli/help.LoomGroup`: the help in eight task sections with `*` on what an agent may run, bare `loom` exiting 0, `delete`/`rm`/`remove` answered, and click's usage errors turned into one `Error:` line naming the command's `--help`, so a `click.Choice` refusal keeps 12.1's error style.
- `tests/output_cases`' `Case.unchanged`: a run that must leave the quilt byte-identical; every dry run and every K3 refusal case carries it.

**By the plan's sections:** every item of 1–7 is built. Departures:
- The closure document a key compile writes moved from `build/bundles/` to `build/closures/`, and the book's per-key "bundle" became "closure document" throughout; "bundle" still names the viewer's built files.
- `ai check` and its code `loom:agent-wrote-outside-run` are gone from the code, the spec and the book.
- Click's own usage errors needed the group's handling above; the plan assumed `Choice` refusals already met the error style.
- `gen_quilts.py` removes `ai/ai-config.toml` after `ai init`, which now writes it: the file is the person's and loom refuses a tracked one.
- Two editor-client defects older than this plan were fixed because they named withdrawn commands: both clients' "bundle" command called `loom bundle` (gone since DR-148) and is now "closure", running `loom source KEY --closure`; loom-lsp offered a whole-file atomize with the withdrawn `--ignore-src`, which is removed, the per-node atomize remaining.
- `NO_AUTHOR_MESSAGE` names `--as NAME`; the `refs` commands still take `--author` until 0.18.5.

**Not done here:** an agent document written from scratch is named by the vocabulary but still refused (`loom:agent-document-not-a-copy`, the orientation's rule); allowing it is its own change.

**Checks:** `scripts/verify full`, every lane; the Neovim client's tests (49) and the VS Code client's type check and lint. By hand on a copy of relloc: `loom --help` reads by task; `loom history`, `history rl-0004` and `history show draft4`; `loom delete rl-0004` explains and exits 2; `loom compile --engine troff` and `loom history rl-zzzz` are refused by name, exit 2; `stamp --dry-run` and `session new --dry-run` leave the copy byte-identical.
