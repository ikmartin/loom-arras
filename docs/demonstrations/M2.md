# M2. Publish and view

## Book says

The synthetic quilt served by `loom serve` renders every page in arras; editing a node re-renders within two seconds; `arras build --prerender` produces a static site of the fixture; the dialect validator passes on every fragment.

## Commands run

loom (`github.com/ikmartin/loom`):

```
uv run pytest -m "not tex"       # unit tier on the shim
uv run pytest -m tex              # real TeX Live, isolated: bundles compile, fixture matches vendored
loom compile drafts/main.tex && loom compile drafts/talk.tex   # in a copy of the synthetic quilt
loom build                        # exit 1: the synthetic quilt carries three intentional errors, and the build is still published
loom bundle sy-0003/proof; loom compile sy-0003
loom serve --quilt demos/demo     # with the vendored viewer, no arras package installed
python scripts/vendor_arras.py ../arras/build
```

workspace:

```
sh docs/specs/tools/refresh-fixture.sh          # real TeX, LOOM_FIXED_TIME=2026-09-16T00:00:00Z
python3 docs/specs/tools/validate-dialect.py docs/specs/fixture/fragments   # 26 fragment(s), 0 problem(s)
```

arras (`github.com/ikmartin/arras`):

```
npm run check                     # 0 errors across 401 files
npm run test:unit -- --run        # 10 tests
npm run test:e2e                  # 23 Playwright tests over the vendored fixture
npm run build:prerender           # 50 routes into site/
npm run build                     # the SPA that loom vendors, without the fixture
```

## Output

- **Every page renders.** The Playwright suite opens home, node (statement and section), master, digest, review, problems, blockers, graph, threads, tags, tag, taxa, taxon, references, and loose against the fixture and checks a heading on each; the node page test checks the fragment, its two proofs, the number `2.1` from the `.aux`, and typeset math (`mjx-container` present); the master test checks an inclusion expanded in place and the nested appendix rendered as an `h2`; the problems test checks every diagnostic code in the manifest appears; unknown state labels and codes render generically; an unaccepted interface version shows one diagnostic and nothing else; search data holds ids, aliases, titles, and tags; live reload follows a manifest change.
- **Edit latency.** On the demo quilt served by `loom serve` with the vendored viewer, an edit to `nodes/dm-0002.tex` produced a new manifest in **0.88 s** (watcher interval 1 s; two fragments re-rendered, the node and its master). The book's bound is two seconds.
- **Static site.** `npm run build:prerender tests/fixture site` wrote 50 routes (one `index.html` per node, master, digest, tag, taxon, and index route) plus the build directory, so any static host serves pretty URLs. The pages are the SPA shell; content loads client-side from `build/manifest.json` (see deviations).
- **Validator.** `validate-dialect.py` reports 0 problems on the 26 fixture fragments; loom's `test_fragment_kinds_and_dialect_validity` runs the vendored copy on every build of the synthetic quilt.
- **Fixture.** `docs/specs/fixture/` holds manifest, 26 fragments, and 1 asset (the PDF figure converted to SVG); the same snapshot is vendored in `loom/tests/fixture/` and `arras/tests/fixture/`, and loom's TeX-tier `test_fixture_matches_vendored` rebuilds it and compares (manifest structurally minus timestamps, fragments textually with SVG bodies normalised because they depend on the TeX Live version).
- **Converter on the fixtures.** Four blocks fall back to SVG in the synthetic quilt (`\parbox` in the master and its section fragment, the tikz-cd diagram, and the beamer title slide); none fail. Bundles for a statement, a proof, and a proposition compile with real TeX.

## Deviations recorded

DR-54 through DR-58: the prerender is a shell prerender (pretty URLs, no server-rendered content); MathJax uses SVG output so no font files ship; per-fragment macro sets are applied with `\renewcommand` inside the fragment's math rather than isolated per fragment; `file://` is unsupported and `loom serve` provides the SPA fallback; the synthetic quilt's missing include sits inside `\iffalse` and its beamer talk declares `proposition` rather than beamer's own environments so both masters compile for numbering. Discoveries without a rule change: `\textcolor` and other colour commands render their content and drop the colour (the dialect has no colour element); a master's preamble yields no fragments; SVG fallback compiles get the quilt root on `TEXINPUTS` so local styles resolve.
