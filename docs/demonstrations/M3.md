## Deviations recorded

- DR-59: a node whose style owes no proof (definition, remark, external) is `proved` once its statement is accepted and fresh; the book's rule required an accepted proof, which definitions never have, so nothing depending on a definition could ever be settled.
- DR-60: annotation ids are allocated over every record in the quilt, not per file, since the book asks for ids unique within the quilt and a per-file counter collides across files.
- DR-61: `loom lint` and `loom check` include the diagnostics derived from records (`loom:detached-annotation`, `loom:retired-ledger-key`, `loom:previous-key-match`, `loom:foreign-annotations`), which the book lists under lint but computes from the ledger and records rather than the source.
- Discovery: `accept` checks that the default master compiles by comparing the PDF's mtime against every scanned file and compiles only when stale; `--force` skips it.
- Discovery: the synthetic quilt's shipped records were produced by running the commands above on a copy and then editing the definition and deleting the retired lemma; the README of the quilt says so.
