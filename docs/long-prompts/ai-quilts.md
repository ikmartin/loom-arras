Prompt 1

There are two upcoming goals that are intertwined.

1. Revamp the mode, block, orientation, and rules system. Make all of these shorter, leaner, and more powerful. The ai should readily reach for relevant blocks and blocks should contain explicit ideas/instructions for utilitizing loom's CLI to the most effective extent possible. Likewise modes should be useful, composable, thematically-distinct programs which guide ai's through a program and enable them to produce maximally useful/correct results without restricting them to a prohibitive script. The orientation and rules documents should be as short as possible without sacrificing any utility. In particular they should provide examples for effectively interpreting prompts, so that "review section 2 of my current document" is interpreted correctly. This requires an audit of the loom CLI as it exists today (along with the addition of new features in all likelihood) and deep consideration of the various workflows users might reach for. One extra bit of information which should almost certainly be sent with every query: the view in the currently focused tab and the view in the active tab in the non-panel document -- so the ai can correctly interpret "referee my currently open document".
