Theorem (Parity)

Let \((X,\sigma)\) be a finite widget. Then \(|X| \equiv |\Fix(\sigma)| \pmod 2\).

Proof First proof

By Lemma Orbits the set \(X\) is a disjoint union of orbits of size one or two.

Proof Second proof

Count fixed points of the permutation \(\sigma\) directly, using (eq:step-ai) from the proof of Lemma Orbits and Definition Widget.
