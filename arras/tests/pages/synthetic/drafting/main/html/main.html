THE SYNTHETIC QUILT

1. Introduction

This paper studies widgets. The basic identity is

\begin{equation}\label {eq:prose} \sigma ^2 = \mathrm {id}, \end{equation}

which we use throughout.1 1The name comes from nowhere. The Gromov–Witten theory of gadgets is not touched. See [1, Chapter II] for schemes and [2, Theorem 2.1] for cycle groups; the lemma [2, Lemma 9] is not in the digest. Note also the dangling reference to Lemma  ??.

Definition 1.1 (Widget). A widget is a pair of a set and an involution of it, so that ( 1) holds. Its fixed locus, the set of its fixed points, is

\begin{equation}\label {eq:fix} \Fix (\sigma ) = \{x \in X : \sigma x = x\}. \end{equation}

Lemma 1.2 (Orbits). Every orbit of a widget has one or two points; compare ( 2) in Definition  1.1.

Proof. The orbit of \(x\) is \(\{x, \sigma x\}\) because

\begin{equation}\label {eq:step} \sigma (\sigma x) = x \end{equation}
by ( 1). □

2. Results

The main results, with one proof deferred to the end of the section.

Theorem 2.1 (Parity). Let \((X,\sigma )\) be a finite widget. Then \(|X| \equiv |\Fix (\sigma )| \pmod 2\).

First proof. By Lemma  1.2 the set \(X\) is a disjoint union of orbits of size one or two. □

Second proof. Count fixed points of the permutation \(\sigma \) directly, using ( 3) from the proof of Lemma  1.2 and Definition  1.1. □

2.1. Consequences.

Proposition 2.2 (Two arguments). A widget with \(|X| = 1\) has a fixed point.

Proof. The only point is fixed. □

Proof. Apply Theorem  2.1 with \(|X|\) odd. □

Lemma 2.3 (Deferred). The composite of two widget maps is a widget map.

Definition 2.4 (Gadget). A gadget is a widget whose involution has no fixed point.

Proof of Lemma  2.3. Both maps commute with the involutions, so their composite does. Here we use Definition  2.4 only for notation. □
